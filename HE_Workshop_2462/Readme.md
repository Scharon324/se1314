### Declaring Variables For Example:

    char - means you can store only 1 character inside.
    int a; - Variable a is going to store integers only: 6, -90
    double b, c;
    float b, c; - b and c are going to store real numbers: 56.3, -45.789
    char p, q; - p and q are going to store single character values.
    char p = 'a';
    char q = '1';
    or
    char p = 'a', q = '1';  
    String m; - m is going to store text strings: "mike", "college"
